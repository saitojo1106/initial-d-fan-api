# v0.2.0 — Second Stage対応

Second Stageの主要なバトルを追加しました。First Stageと合わせて、10人・10車種・5峠・12対戦を参照できます。

## 追加内容

- 岩城清次・須藤京一・秋山渉
- ランサーエボリューションIII・IV、AE86カローラレビン
- 赤城・正丸
- 中里対清次、拓海対清次、拓海対京一、涼介対京一、拓海対渉の5対戦
- バトルの`stage`フィールドとStage別の絞り込み

```sh
curl -s 'https://initial-d-fan-api.saitoudayooooon-jo.com/api/v1/battles?stage=second-stage' | jq
```

`stage`は`first-stage` / `second-stage`。キャラクター・峠の条件とも組み合わせられます。省略時は全Stageを取得します。

## 利用時の注意

- キャラクターの戦績は全収録対戦の合算です。拓海は8勝1敗・9対戦となります。
- 赤城の京一戦はエンジンブローによる走行終了を拓海の敗戦として集計します。
- バトルのJSONに`stage`が追加されるため、厳密なスキーマ検証を行うクライアントは対応してください。
- Third StageやBattle Stageの追加対戦は含めていません。
